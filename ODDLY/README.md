# ODDLY — A WORLD FULL OF SURPRISES.

Production repository for the ODDLY 2D animated series. No narration, no dialogue: music and sound effects only.

## Layout
- `DEVELOPMENT/CONCEPTS_001-050.json` — concept registry, batch 001 (premise, hook, conflict, ending, scores). New concepts must not repeat a central conflict listed here.
- `DEVELOPMENT/RANKING_TOP20.{json,md}` — ranked shortlist, generated by the tool below.
- `TOOLS/rank_concepts.py` — `python3 TOOLS/rank_concepts.py DEVELOPMENT/CONCEPTS_001-050.json DEVELOPMENT 20`
- `EP###/{CHARACTERS,BACKGROUNDS,SCENES,ANIMATION,AUDIO,THUMBNAIL,PUBLISHING}` — created when a concept is greenlit for production.
